共用元件範本

上半部依試算表「BS主規則」整理，每條規則附 CSS class、範例網頁與 HTML 用法，可直接複製使用；最後是廣告版位、各種 Modal，以及 Compare、Gallery 等互動元件。

標題與文字（#1–#6） 分隔線與區塊（#7–#9） 標籤（#10–#13） 按鈕（#14–#18） 卡片（#19–#19） 狀態與資料呈現（#20–#21） 廣告 Modal 元件（Compare、Gallery）

範例網頁：符合：common/about、符合：articles/list
